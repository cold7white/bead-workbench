# Bead Workbench · 拼豆图纸工作台

把 MagicaVoxel 的 `.vox` 体素模型转成可照着拼的 **MARD 拼豆图纸**。

单文件 HTML、纯前端本地解析，不需要服务器，模型文件也不会被上传到任何地方。

![界面截图](screenshot.png)

## 功能

- **自动解析 .vox**：自写 VOX 二进制解析器（递归读取 SIZE / XYZI / RGBA chunk），拖入即出图
- **自动拆件**：按六邻接连通分量把模型拆成独立零件
- **拍平成面**：每个零件按最薄的那一维拍平，得到拼豆用的平面图
- **排版装箱**：按面积排序 + 行装箱，把多个零件排进同一张图纸
- **MARD 221 色匹配**：RGB 欧氏距离取最近色号，支持手动改色号、填色号编码、自定义取色
- **矢量渲染**：整张图纸由内联 SVG 生成，左侧预览支持滚轮缩放、拖拽平移、双击适应窗口，放大到 300% 依旧清晰
- **图纸要素齐全**：页眉信息、四角裁切标记、细网格 + 5 格粗线、格内色号、零件编号、颜色图例与每色颗数
- **导出**：SVG 矢量图（可直接进 Illustrator 或打印）、1× / 4× PNG

## 使用

1. 下载 `index.html`，双击用浏览器打开（Chrome / Edge 都行）
2. 把 `.vox` 拖进页面，或点「看示例模型」先试
3. 右侧调「格子大小」「零件间距」「颜色映射」
4. 左侧工具条缩放视图，底部三个按钮导出

没有 .vox 文件时，示例模型（16×13 像素画猫咪 + 小鱼）会给出 2 零件 / 318 颗 / 4 色 / 14×19 格的完整图纸。

## 技术说明

- 单文件、零依赖、原生 JS，无构建步骤
- 图纸不使用 Canvas 位图，全部由内联 SVG 拼接生成（网格与 5 格线用单条 `<path>` 合并 subpath，控制节点数量）；缩放只改 svg 的 CSS 宽高，由浏览器做矢量重采样
- 透明色块（MARD `H1`）用 SVG `<pattern>` 棋盘格表示
- 导出 PNG 走 `data:image/svg+xml` → `Image` → `canvas.drawImage` 光栅化，因此 4× 导出依然是矢量描边而非像素放大

## 已知限制

- MARD 色号是按 RGB 近似匹配的，实际购买请以官方色卡为准
- 拍平逻辑对"厚度大于宽度"的零件会按最小维度选择平面，极端形状可能不是你想要的那一面（可在 MagicaVoxel 里调朝向）
- 一次只处理一个模型文件
